桌面宠物 —— 使用说明
========================

怎么用
------
1. 把整个「桌面宠物」文件夹解压到任意位置（比如桌面）。
   注意：必须整个文件夹一起带走，exe 需要旁边的 _internal 目录。
2. 启动方式（任选其一）：
     * 双击**桌面上的「桌面宠物」快捷方式**（推荐；程序本体装在 C:\桌面宠物）
     * 双击 **C:\桌面宠物\桌面宠物.exe**（exe 和 _internal 要在同一个文件夹）
     * 源码版：在项目目录里双击 启动桌面宠物.lnk 或 start_pet.bat
3. 关掉它：右键宠物 ->「退出」，或右键右下角「^」里的校徽图标 ->「退出」。

⚠ 为什么装在 C:\桌面宠物 而不是桌面上：本机的管控软件**不允许从桌面目录运行的
  程序调用系统托盘 API**（实测 Shell_NotifyIcon 返回 err=5 Access Denied；同一个
  exe 挪到 C:\ 下就正常）。放在桌面上的话宠物能跑，但托盘图标会加不上（程序会
  不会再退回任务栏按钮，后台会一直重试）。

  2026-10 实测：连 `C:\Users\...\Desktop\desktop-pet\dist\桌面宠物\桌面宠物.exe`
  这种"桌面下面的构建目录"也会被拦（托盘 tray_ok=False）；同一份 exe 放到
  `C:\桌面宠物` 就 tray_ok=True、图标出现在右下角「^」里。所以**日常请从
  C:\桌面宠物 启动**，dist 那个目录只当构建产物看。

⚠ 千万别运行 **build\ 里面的 exe**：那是打包过程的中间产物（PyInstaller 的工作
  目录），旁边的 _internal 不在那儿，双击会报
  「Failed to load Python DLL ... python312.dll」。看到 dist\ 里的才是能跑的。
  build\ 整个目录都可以删（下次打包会重新生成）。

「打开文件 - 安全警告 / 无法验证发布者」是什么
--------------------------------------------
那不是病毒报警，是 Windows 给**从网上下载/解压出来的文件**打的标记
（Mark of the Web）在拦 .bat 这类脚本。三种消除办法：

  1. 用文件夹里的 **启动桌面宠物.lnk** 启动 —— 快捷方式不会触发这个警告。
  2. 已经解压好了：在文件夹里按住 Shift 右键 ->「在此处打开 PowerShell 窗口」，
     执行：   Get-ChildItem -Recurse | Unblock-File
     （这个文件夹我已经执行过一遍，38 个文件都清干净了。）
  3. 下次重新下载时：**先**右键那个 zip -> 属性 -> 勾「解除锁定」-> 确定，
     然后再解压，解出来的文件就都不带标记了。

  如果清了标记还弹，那就是电脑上的安全软件（不是 Windows 自带）在拦 .bat，
  用第 1 条的快捷方式，或者把它加进白名单。

它在哪一层
----------
它永远待在**最底下**：盖在所有普通窗口下面、但在桌面图标和壁纸上面。
所以它不会挡住任何窗口，也不会浮到前面来；如果你开着最大化的浏览器，
就看不见它——这是设计如此。

  有全屏窗口时自动停：前台出现真正的全屏窗口（游戏、全屏视频、演示文稿，
  判断依据是"窗口铺满整个显示器且没有标题栏"）时，它会先把自己藏起来，
  动画、气泡、AI 请求全部停下；退出全屏后 1 秒左右自己回来，位置不变。
  这个行为可以在 设置… -> 偏好 -> 「全屏时停用」里关掉。

  被别的窗口完全盖住时也会自动暂停（不跑动画、不联网），等重新露出来再继续。

操作
----
  左键单击   它才说话（气泡只在点击后出现，不会自己冒出来占屏幕）。
             不想要这个的话，设置… -> 手势 -> 关掉「点击说话」，
             之后就只跳一下、不弹气泡
  左键拖动   拖到任意位置（至少留一角在屏幕内，拖不丢）
  双击       打开对话框跟它聊天
  右键       菜单（功能都在这里：形象 / 大小 / 不透明度 / 音乐 / 对话… /
             设置… / 刷新一下…）
  托盘        启动后只在**系统托盘**（右下角小箭头「^」里面那排）放一个图标，
              图标就是**莆田一中校徽**：右键 -> 跟它说话 / 对话… / 设置… /
              刷新一下 / 取消鼠标穿透 / 退出；左键点它，宠物跳一下。
              它**不会**出现在任务栏里（任务栏上不再有按钮），Alt+Tab 也看不到。
              如果系统不让加托盘图标（有些管控软件会拦，pet_stderr.log 里会写
              "tray: NIM_ADD failed"），程序每 3 秒自动重试、最多 1 分钟；
              仍然失败也不往任务栏塞按钮 —— 把 exe 放到 C:\桌面宠物 再启动就行
              （桌面目录会被拦，见上面的 ⚠）。
  被划一下   鼠标从它上方快速向下划过，它会"被压扁"再弹回来
  上划       鼠标快速向上划，它会开心地跳一下
  摸头       鼠标在它头顶左右来回蹭，它会跟着手晃、往下缩一点，冒爱心/小星星/拍头圈
             chm_love_me.png 这张图摸头时还会从头顶往上漂一条中日双语弹幕：
             「きもちいい〜 / kimochi ii · 好舒服～」（其他形象没有）
  身体横划   在它身体中段快速横着划一下，它会往反方向躲一下
  绕圈       鼠标绕着它画一圈，它会转晕、冒小星星
  摇一摇     在它身上（身体中段）左右快速摇：它会把脑袋摇起来喊"别摇啦"；
             想让它在这个手势下刷新，设置… -> 手势 -> 打开「摇一摇刷新」
  双下滑     0.9 秒内连着向下划两次，它会开心地弹一下、冒爱心
  长按头顶   按住头顶不动一秒，等于摸头（懒得来回蹭的时候用）
  被窗口挡住   手势照样认得出来（只是姿势不画出来）；想刷新就点托盘/右键的
               「刷新一下」或设置窗口里的按钮
  右键 -> 逗它玩
             摸头 / 跳一下 / 压扁 / 转圈圈（晕）/ 躲一下 / 打飞机（chm）
             打飞机：天上飞过小飞机，chm 拉长变窄，从头顶连续发射子弹，
             打中飞机有爆炸；只有 chm_love_me.png 会这个特技
  挂机       不弹气泡；它在后台悄悄备好一句，你一点就立刻说出来

设置窗口
--------
右键 ->「设置…」（或托盘菜单 ->「设置…」）会打开一个单独的设置窗口。
**这里只放"设置性"的开关**，点一下就生效、不用按保存，右下角「完成」是关窗口；
换形象、调大小、放音乐、让它做动作这些**功能**仍然在右键菜单里。

  偏好   窗口：鼠标穿透 / 显示气泡
         启动：开机自动启动
         桌面显示：全屏时停用
         卡死急救：卡死自动刷新
  手势   手势互动（鼠标划过时压扁、跳、躲、转圈、摸头）/ 摇一摇刷新 /
         点击说话；下面还写着手势清单
  外观   气泡停留时长（2/4/6/8 秒）/ 动作幅度（安静 / 正常 / 活泼）/
         手势灵敏度（迟钝 / 正常 / 灵敏）
  对话   启用 AI / 说话带颜文字 / 清空记忆 / 设置 API Key
  关于   校徽、版本、素材目录入口

「卡死自动刷新」关掉以后，看门狗就不会自己救，得手动点「刷新一下」或者重启。

顺带说几个细节：
  * 「手势互动」关掉只是不再**自动**响应鼠标划过；右键 -> 逗它玩 里的动作
    仍然随点随做。
  * 「动作幅度」只管划动触发的动作幅度：安静一点适合上班摸鱼，活泼一点
    跳得更高、晃得更明显。
  * 「手势灵敏度」调低以后要划得更快更远才算数（打字时手从屏幕上扫过
    不容易误触发）；调高以后轻轻一带就有反应。
  * 「摇一摇刷新」默认关：摇一摇只是摇头卖萌；打开以后摇一摇等于点一次
    「刷新一下」。
  * 「点击说话」关掉后，单击只跳一下、不弹气泡，省得误点就冒一句话。
  * 「鼠标穿透」开着时鼠标点不到宠物，想关掉就右键托盘图标 ->
    「取消鼠标穿透」（设置窗口里也能关）。它不记忆，下次启动总是可点的。
  * 窗口可以按住标题栏拖走；按 Esc 或右上角 × 关闭；关掉再打开还是同一个
    窗口，不会越点越多。

刷新（卡死之后怎么办）
----------------------
右键 ->「刷新一下」，或者托盘菜单 ->「刷新一下」，或者设置窗口右下角
「刷新一下」。它会就地重新把气泡、动画、鼠标钩子都收拾一遍：
  * 气泡卡在那儿消不掉、点了没反应、动画停住 —— 点一下这个就行，
    不用去任务管理器结束进程
  * 刷新不会重置形象、大小、好感度、对话记忆，只是把界面重新接起来

程序自己也有看门狗（默认开着，设置 -> 偏好 -> 「卡死自动刷新」）：
  4 秒没动静   只在 pet_error.log 里记一笔
  9 秒没动静   自动按一次「刷新」，并把卡住的气泡窗口先藏掉
  25 秒还没好  直接重启自己（启动参数、形象、位置都照旧）

真卡死在截图/演示的时候也能救：设置窗口里点「刷新一下」即可。

跟它聊天（中文输入）
--------------------
双击宠物，或右键 -> 对话…，会打开一个常驻的对话窗口（红白色系，左上角是校徽）：

  对话框里有什么
    对话记录   你和它说过的话都在上面（你的靠右、它的靠左）
    好感度     右上角的红条 + 数字，0-100，会跟着聊天内容涨落
    三个选项   "你可以这样回："下面三个是 AI 生成的候选回复，
               点一下就直接发出去（不用自己打字）
    输入框     原来的手打输入框还在，想自己写就自己写，Enter 发送
    关闭       Esc 或「关闭」按钮；窗口开着的时候可以继续逗宠物

  好感度：初始 10，聊得贴心会加，敷衍/没礼貌会减（每次 -5 ~ +5），最高 100。
  它说话的语气和称呼会跟着好感度变（数字它不主动提，你问它会嘴硬糊弄）：
    0-20   陌生期   叫"喂 / 那个谁 / 观众"，冷淡、赶人、装酷
    21-40  熟悉期   叫"经理 / 同学 / 笨蛋"，嘴碎、互怼、偷偷照顾
    41-60  朋友期   叫"你"或名字，会主动找你，但嘴硬不承认
    61-80  暧昧期   吃醋、脸红、破防（嘴上还是不承认）
    81-100 恋人期   叫"我的 MVP"，撒娇、依赖、直球但害羞
  上面这五档的**称呼**是陈瀚铭的；郑迪隆按他自己的叫法（同学 / 笨蛋 /
  小笨蛋 / 我的同桌 / 我的 MVP、专属同桌）。黄世举只有通用语气。
  右键 -> AI 设置 -> 清空对话记忆 会把**当前形象**的记忆和好感度一起重置。

  恋爱（现阶段陈瀚铭、郑迪隆）：好感度攒满 100 后，"你可以这样回："第一位会多出
  一个红色的「♡ 恋爱」选项 —— 点它，它会说那句告白，之后你们就是恋人了
  （它的话会变得更亲近）。陈瀚铭说的是"前辈请与我交往吧"；郑迪隆说的是
  "月色真美"（就是"我喜欢你"的意思，他不承认）。这个状态会记在配置里，
  重开还是恋人；黄世举（内置那三张）没有这一项，好感度满也不会有。
  想重新开始：右键 -> AI 设置 -> 清空对话记忆（恋人状态一起清掉）。

  人设（每个形象一套）：它说话的语气也跟着**形象**变，每个形象有自己的记忆和
  好感度，切形象 = 换人，切回来还是原来那份：

    内置三张（中性灰 / 浅色桌面 / 深色桌面）  ->  黄世举（话痨朋友）
    chm_love_me.png（捧花少年那张）          ->  陈瀚铭（闷骚少年）
    郑迪隆.png（照片抠出来的那张）            ->  郑迪隆（骚话少年）

  想给某张图指定人设：右键 -> AI 设置 -> **这张图的人设**（选一次就记住）。
  也可以直接改配置，例如
      "personas": { "你的图.png": "闷骚少年" }
  可用的人设名见 ai_client.py 里的 PERSONA_PROMPTS（没登记的用默认人设）。

  输入法：输入框是标准 Windows 窗口，已显式挂上 IME（ImmAssociateContextEx
  + WM_IME_SETCONTEXT），并把窗口抢成**前台+活动窗口**再设焦点；抢不到时会
  每 150ms 重试，最多盯 5 秒（别的程序/任务栏的菜单占着键盘时，等它让出来
  就自动接管）。实在抢不到，提示行会写"点一下输入框即可打字"。
  还可以：在别处打好字，Ctrl+V 粘贴进来。

  Enter 发送 · Esc 关闭 · 「发送 / 关闭」按钮是标准尺寸，好点。

  AI 设置 ->
    启用 AI       关掉就只用内置话术，完全不联网
    设置 API Key… 换成你自己的 DeepSeek key；支持多个，用逗号分隔
                  多个 key 会轮流用，401/402/429 自动换下一个；留空 = 用内置的两个
    清空对话记忆  忘掉之前聊过什么，并重置好感度
    好感度: N/100 当前好感度（不可点，只是显示）

  AI 关掉时窗口照样能开，只是没有三个候选回复（内置话术兜底）。

好感度怎么涨
------------
每轮聊天都会产生好感度变化（AI 给 -5~+5；如果它偷懒给 0，程序会保底 +2，
明显冒犯的话保底 -2）。正常聊天、关心、接梗都会涨。

脾气（吃醋 / 冷战 / 嘴硬）
--------------------------
它会真的闹别扭。判顺序是 **冷战 > 吃醋 > 日常**：

  * 吃醋：你提别的男生、夸别人、跟别人玩、拿人跟它比、说「随便你」，
    或者隔了很久才回它 —— 它就阴阳怪气、回得很短（「然后呢」「他谁啊」
    「他很好？」），问它它也绝不承认。哄它，它嘴上说「谁要你哄」，其实已经软了。
  * 冷战：敷衍它（「哦」「嗯」「随便」）、嫌它烦或嫌它嘴碎、说它比不上别人、
    骗它、放它鸽子、当众拆穿它嘴硬、吃醋了还不哄 —— 它只回「嗯」「哦」「随你」；
    你问怎么了，它只说「没事」「你想多了」。有时候它会**发一条又撤回**，或者手滑
    点赞你很久以前那条消息。认真哄一句、道个歉、夸它、说想它，它就顺着台阶下来
    （「明天有训练，爱来不来」）。拖得太久它会漏一句「行吧，你忙你的，GOAT 自己练」。
  * 嘴硬心软：你夸它、关心它，它嘴上「还行吧」「基操」「别多想」，
    旁边多半跟着一个看得见的小动作（耳尖红、别过脸、清嗓子、塞手机）。

生气的时候，聊得再好也不给好感度（冷战只扣不加，吃醋最多 +1）。
放它一天不说话，它自己就气消了（会别扭一句「……你还知道回来」）。
右键菜单里「好感度」那行后面会挂着当前状态（· 吃醋 / · 冷战）。
这套脾气跟人设走：每个形象各气各的，切换形象互不影响。

郑迪隆（骚话少年）
------------------
郑迪隆，生日 2011 年 10 月 11 日，莆田一中初中部九年七班，初三。跟陈瀚铭一样
是纯聊天恋爱 AI，但风格完全不同：闷骚、爱调侃、有点中二、嘴硬心软，日语骚话
张口就来，说完补一句「……日语课学的，别多想」，被追问就「听懂算你赢」。

  * 口头禅「気持ちいい」，每 2~3 句冒一句日语骚话（纯爱向，不低俗）。
  * 日语台词下面会自动补一行中文翻译，例：
        気持ちいい
        （好舒服啊）
    翻译按骚话库补（気持ちいい / ちょっとドキドキする / ずるいよ / もう一回 /
    バカ / 毎日会いたい / 離さないよ / もっと近くに来て / 君だけだよ / 嘘つき /
    寂しい / 抱きしめたい / 好きすぎて困る …）；库里没有的日语，它会在括号里
    自己给中文。中文暗号「月色真美」故意不翻译。
  * 两个暗号（他都死不承认是告白）：
        「月色真美」              = 我喜欢你（夏目漱石那个梗）
        「君のこと、好きだよ」     = 喜欢你哦
    你回其中任何一句 = 接受告白，他会大幅破防；回「我也喜欢你」他会脸红到脖子，
    嘴硬「谁问你了」，再小声补「もう一回……再说一遍」。
    好感 61 以上两个暗号开始成对出现，81 以上两句连着说，说完还嘴硬
    「気持ちいい……我是说月亮」。
  * 说日语前会在桌上敲两下（像在打草稿），说得特别顺、说完低头看手机；被拆穿
    就清嗓子、别过脸、敲桌子节奏变乱 —— 旁白只写看得见的动作，不点破。
  * 特技跟陈瀚铭一样：摸头冒日语弹幕（日文一行、中文一行），右键「打飞机」
    也有（菜单里写的是「打飞机（chm / 郑迪隆）」）。
  * 不聊乒乓球；别人那个口头禅他也不说。

小游戏（右键 -> 玩法 -> 小游戏）
--------------------------------
四个都能一手点完、随时关掉，不联网、不占资源：

  * 猜拳    三局两胜，先赢两把算赢。
  * 猜数字  它心里想一个 1 ~ 100 的数，用"大了 / 小了"缩小范围；
            5 次以内猜到算赢。
  * 翻牌记忆 4 x 3 共六对图案，翻到一样的配对；10 步以内配完算赢。
  * 打地鼠  30 秒，地鼠冒头就点，点中 +1；15 分以上算赢。

  * 赢了（或达标）给好感度：猜拳 +1，其余最多 +2，**每局只加一次**，
    输了不加也不扣。
  * 窗口贴着宠物弹出来（上 / 下 / 左 / 右找地方，都不行才塞进屏幕里）；
    Esc 或右上角 ✕ 关掉，不会关掉桌宠本身。
  * 它会跟着人设说几句话（陈瀚铭嘴硬、郑迪隆带日语、黄世举话痨），
    台词写在 pet_games.py 的 LINES 里，想改直接改那个表。
  * 界面是画出来的圆角卡片：按钮有悬停浮起和点击涟漪，赢了会冒星星和
    "+1" 飘字，翻牌有翻页动画，地鼠从洞里钻出来；没有系统标题栏
  * 标题栏可以按住拖动，把窗口挪到别处；右上角 ✕ 关掉
  * 键盘也能玩：猜数字 0 ~ 9 直接按、BackSpace 退格、Enter 提交；
    所有窗口按 Esc 关掉
  * 关掉窗口不会打断桌宠，它该干嘛干嘛；同一个游戏再点一次会重新开一局
  * 成绩存在配置里（打地鼠最高分、猜数字最少次数、翻牌最少步数、猜拳赢
    的次数和各自玩了多少局），菜单最下面那行会跟着更新；「重置」会一起清空。

重置（恢复出厂）
----------------
右键 ->「重置」，确认后会：
  * 清空**所有形象**的对话、记忆、摘要、轮数
  * 所有形象的好感度改为 10，恋爱状态关闭，脾气一起清空
  * 形象回到「中性灰.png」，大小 50%、气泡开、AI 开、手动手势开、全屏暂停开、
    卡死自动刷新开、右下角、不透明
  * 自定义人设映射清除
  * **API Key 和模型保留**，不会把 key 重置掉

它记得最近几轮对话，聊多了会自动压成摘要（省 token），存在 pet_config.json。

换形象（放你自己的图片）
------------------------
1. 右键 -> 形象 -> 打开图片文件夹（exe 旁边的 image\ 目录）
2. 把图片（png / jpg / jpeg / bmp / gif / webp）丢进去
3. 右键 -> 形象 -> 重新扫描图片文件夹，菜单里出现文件名，点它即可切换

   * 自动缩放到**和内置立绘一样高**（463），所以「大小」菜单选同一档时，
     各个形象看起来一样高；照片是竖构图的话会窄一些，但高度一致
   * 白底照片能直接用：取四条边上最多的颜色当抠底色，把背景抠掉
   * 想把照片做得更干净（去掉白边、底部渐隐、自动裁掉空白），可以用
     tools\make_photo_sprite.py：
         python tools\make_photo_sprite.py 照片.png image\新形象.png
     郑迪隆.png 就是这么从照片抠出来的
   * 带透明通道的 PNG 会保留透明（自动切到逐像素 alpha 渲染）
   * 内置三张（中性灰 / 浅色桌面 / 深色桌面）也在 image\ 里，可直接替换；
     image\ 里还附了一张「捧花少年」（用 tools\make_form.py 做的，见下）
   * 背景特别花的图抠不干净，建议先用带透明通道的 PNG

   ⚠ 本机的 layered（逐像素透明）后端**测出来一个像素都不画**（实测 0.0%），
   所以带透明通道的 PNG 放进去会看不见东西。要加这种图，先用
     python tools\make_form.py <透明底图.png> <输出的名字.png>
   转成"纯色幕布"版本（工具会自动挑一个离人物最远的饱和色当底色，
   程序启动时会自动把它抠掉；边缘的描边/挖洞问题也在这一步处理好）。

右键菜单里还有什么
------------------
  形象 / 大小（40-100%，默认 50%）/ 不透明度 / 对话… / AI 设置（Key、清空记忆、
  模型、好感度、人设）/ 音乐 / 打开网页 / 说点什么 / 逗它玩 / 小游戏 / 设置… /
  刷新一下（卡死急救）/ 修改器… / 重置 / 来一个颜文字 / 回到右下角 /
  打开图片文件夹 / 渲染后端 / 退出

  （显示气泡、手势互动、说话带颜文字、点击穿透、全屏时停用、卡死自动刷新这些
  **开关**都挪进了设置窗口；右键里只留"点一下就要它做点什么"的功能。）

不透明度
--------
  右键 -> 不透明度，或直接在宠物上 **Ctrl + 滚轮**（每格 5%）。
  范围 20% ~ 100%，每次都从 **100%** 开始（不记忆）。

音乐
----
把歌丢进 exe 旁边的 music\ 文件夹（mp3 / wav / m4a / flac / ogg / wma 都行），
右键 -> 音乐 里会一首首列出来，点哪首放哪首。

  播放时          头顶**一直**挂着「正在播放：歌名」，直到停下/暂停
  气泡上的按钮    «（上一首）/ ←15s（后退 15 秒）/ 停止 / 15s→（快进 15 秒）/
                  »（下一首）
  快捷键          点一下宠物或那个气泡，然后：空格 = 停止，← = 后退 15 秒，
                  → = 快进 15 秒，[ = 上一首，] = 下一首
  上一首 / 下一首  右键 -> 音乐 -> 上一首 / 下一首（或上面那两个键）
                  首尾相接成循环：在第一首往前会到最后一首，
                  在最后一首往后会回到第一首
  暂停 / 继续     右键 -> 音乐 -> 暂停 / 继续
  停止            右键 -> 音乐 -> 停止
  音量            ±10%，默认 60%
  一首放完        自动接下一首（按文件名顺序，最后一首回到第一首）
  加了新歌        右键 -> 音乐 -> 重新扫描 music 文件夹
  打开文件夹      右键 -> 音乐 -> 打开 music 文件夹

  气泡被别的窗口整个盖住时会跟着藏起来（宠物自己也被盖住了），
  窗口移开、重新露出来之后会自动挂回去；中间说别的话也不会把它顶掉，
  那句话说完几秒后控制条自己回来。

  为什么快捷键要先点一下：本机的安全软件不允许装全局键盘钩子，而且把
  空格注册成系统级热键会把所有程序里的空格都吃掉。所以这几个键只在
  宠物/气泡自己拿到焦点时生效 —— 点一下它就行，不影响别的地方打字。

现有两首：See you again、朋友的酒（打包部署时会自动同步到 C:\桌面宠物\music）。
放歌不联网、不动系统音量；退出宠物时歌会一起停。

打开网页
--------
  右键 -> 打开网页，里面列了常用站点，点一下就用**系统默认浏览器**打开：

    Bilibili / GitHub / DeepSeek / 豆包 / 知乎 / 微博 / YouTube / 百度

  只是调用浏览器打开网址，不在程序里嵌网页，也不上传任何东西。
  想加新站点改 desktop_pet.py 顶上的 WEB_LINKS 就行（一行一个）。

自己加网页
----------
  右键 -> 打开网页 -> ＋ 添加网页…，填「名字」和「网址」点保存：

    名字       菜单里显示的那行字，随便起（比如 Bilibili 直播）
    网址       可以只写 live.bilibili.com，会自动补 https://
    保存       它会说一句「记住了：…」，菜单里立刻多一项

  加过的会写进 pet_config.json，重开也还在；不想要了就
  右键 -> 打开网页 -> 删除自己加的网页 -> 点那个名字。
  内置的那 8 个删不掉，也不会被你新加的同名项顶掉。

颜文字
------
  右键 -> 颜文字 打开（默认开）。开着的时候它会**按心情给自己的话后面贴一个**
  颜文字：好感度低的时候偏冷淡（(￣^￣)、(￣皿￣)），越熟越软（(〃▽〃)、(///ω///)），
  另外摸头、喂饭、给糖这些动作会贴"害羞"的，很久不理它会贴"无语"的。
  说的话里本来就有颜文字时不会重复贴。
  菜单里「来一个颜文字」会让它当场说一句带颜文字的话（测试用）。
  关闭后它说话就干干净净，聊天回复也不再贴。

  注：颜文字是代码按心情挑的，不是模型编的 —— 这样不会偶尔蹦出一大串表情，
  也不会忘掉。气泡里的字是 Pillow 画的、没有字体回退，所以词库里只用
  确认能画出来的符号（♡、∀ 这类个别字体缺的字符会画成方块，已经剔掉了）。

第一次打开出现在哪
------------------
  **每次打开都出现在屏幕右下角**（离右边 48 像素、脚踩在任务栏上沿）——
  位置不记忆，这样不管上次拖到哪儿（或者配置文件里留着什么坐标），一开就在
  右下角。拖走之后本次运行期间当然会待在原地；右键「回到右下角」也是回那里。
  对话框会贴在宠物上方（上面放不下才挪到下面），不会盖住宠物。

设置会记住
----------
形象、大小、气泡开关、手势互动、点击说话、全屏时停用、卡死自动刷新、AI 开关、
对话记忆、好感度、脾气（吃醋/冷战）都存在 exe 旁边的 pet_config.json，下次打开自动恢复。
删掉它就回到初始状态。
（位置和不透明度例外：位置每次开机固定右下角，不透明度每次都是 100%；
  鼠标穿透也不记 —— 它是一次性的"点不到"状态，免得下次打开点不着。
  层级也不记：它永远在最底下。）

如果 AI 不回话
--------------
1. 气泡里会直接显示原因：API Key 好像不对（401）／余额不足（402）／
   请求太频繁（429）／连不上 DeepSeek。
2. 公司网络要走代理：先设 HTTPS_PROXY 再启动。
3. 想完全不联网：设置… -> 对话 -> 关掉「启用 AI」，或用 --no-ai。
4. 命令行测一句：  桌面宠物.exe --ask "你好"

如果看不到宠物
--------------
1. 确认整个文件夹解压完整（不能只拷 exe）。
2. 它永远在最底层，被最大化的窗口盖住就看不见 —— 最小化那个窗口。
3. 是不是有全屏窗口开着？全屏时它会主动躲起来（设置… -> 偏好 ->
   「全屏时停用」可以关掉这个行为）。
4. 右键托盘图标 ->「跟它说话」/「刷新一下」，或右键宠物 ->「回到右下角」。
5. 命令行自检：--where / --list-images / --style colorkey /
   --scale 0.75 / --selftest 3000
6. 程序目录里的 pet_error.log 会记录异常堆栈和看门狗的卡顿记录，
   pet_stderr.log 记 C 层的致命错误（Tcl 崩溃那种）。

隐私
----
只用到 DeepSeek 的对话接口：发出去的是你输入的那句话、最近几轮对话和一句
人物设定，不会上传屏幕内容或本地文件。

打包成 exe（只有改源码才需要）
------------------------------
⚠ **别直接跑 `python -m PyInstaller --distpath dist`。**
   PyInstaller 会把 dist\桌面宠物 整个目录删掉重建，image\ 里自己加的立绘、
   music\ 里的歌、pet_config.json（形象/好感度/聊天记忆）会一起没。
   桌面宠物 这个项目里已经踩过一次，别再来第二次。

正确做法：用仓库自带的打包脚本，它先把 exe 打到 build\_stage_dist\，
再只覆盖 dist\桌面宠物 里的 桌面宠物.exe 和 _internal\，
image\ / music\ / pet_config.json 一个都不动，打包前还会把用户数据备份到
build\_dist_data\<时间戳>\：

      & "$env:USERPROFILE\.dsh\dsh-runtimes\dsh-primary-runtime\dependencies\python\python.exe" `
        tools\build_exe.py

   （tools\build_exe.py 只做目录版：构建完更新快捷方式、同步到 C:\桌面宠物，
    不会再编单文件版。）

这台机器上 pip 直接装 PyInstaller 会被拦（下载能成，落盘 .whl 时报
Permission denied），所以仓库里放了一条绕路：先把 wheel 抓到本地、解到
pylibs\，再用 PYTHONPATH 把 pylibs 并进去跑打包。

      # 1) 抓 wheel（走 PyPI 镜像，用 urllib 下，不经过 pip 的临时目录）
      & "$env:USERPROFILE\.dsh\dsh-runtimes\dsh-primary-runtime\dependencies\python\python.exe" `
        tools\fetch_wheels.py

      # 2) 解到 pylibs\（wheel 就是 zip，直接解，不用 pip install）
      #    这一步只有第一次需要；之后直接跳到 3)

      # 3) 打包（目录版推荐，启动快、不解包）
      #    手动跑时务必用 --distpath 指到空目录，别对着 dist\桌面宠物 打
      $env:PYTHONPATH = "$PWD\pylibs"
      & "$env:USERPROFILE\.dsh\dsh-runtimes\dsh-primary-runtime\dependencies\python\python.exe" `
        -m PyInstaller --noconfirm --clean --distpath build\_stage_dist desktop_pet.spec
      产物：build\_stage_dist\桌面宠物\（再拷 exe + _internal 到 dist\桌面宠物\）

  只做目录版：启动快、不用解包，也不会被临时目录策略拦。单文件版已经停用，
  仓库里不再构建它（旧的 dist_onefile\ 也已删掉）。

  实测：窗口出现在右下角 (1014,561)-(1232,800)，自动在 exe 旁边建 image\，
  日志为空；拷到别的目录（不带着源码）也能单独跑。

  build\ 是打包中间产物，可以随便删（下次打包会重新生成）；**不要运行 build\
  里的 exe**（那是半成品，会报 Failed to load Python DLL）。

技术说明
--------
Python 3.12 + tkinter + Pillow + DeepSeek Chat API，PyInstaller 打包。
AI 请求在后台线程，界面不卡；线程与 Tk 之间用队列传递结果。

桌宠固定在窗口最底层：启动时和运行中每 1.5 秒 SetWindowPos(HWND_BOTTOM)，
所以它永远在普通窗口下面、桌面图标（Progman/WorkerW）上面；被盖住时暂停动画
（沿 Z 序往上找"把宠物整个包住的窗口"，上限 500 个，实测本机要往上走 67 个）。

全屏检测：GetForegroundWindow 拿前台窗口 -> 可见、没最小化、不是最大化
（IsZoomed）-> 类名不是桌面/任务栏 -> **有 WS_CAPTION 标题栏就不算**（普通
"最大化"窗口的矩形也铺满整屏，靠这条排除）-> 矩形完全覆盖所在显示器才算真全屏。

卡死兜底：主线程每帧写一次心跳，后台看门狗线程盯着它，4 秒记日志、9 秒急救
（只往主窗口 PostMessage：WM_CANCELMODE，必要时补 ESC，并把气泡窗口藏掉）、
25 秒还没好才重启进程。急救路径**绝不碰 Tk**——跨线程调 Tcl 会直接把进程
带崩（0xC0000409），所以句柄都是主线程算好、只读 int 传给看门狗。

"被划一下"每帧读光标位置（GetCursorPos）检测，装了全局鼠标钩子时优先用
钩子送来的采样。光标采样放在"被盖住就暂停"的判断**之前**：桌宠固定在最
底层，桌上开着别的窗口时 visible 会是 False，采样不能跟着停，否则看起来
就是"手势失灵"。判定一次划动只看最近 0.18 秒的位移，并且会丢掉"光标刚
从别处瞬移过来"的那几个旧采样，所以"从屏幕另一头甩过来再划"也认得出来。

被盖住的时候姿势状态会被清零（不再画动作），这是故意的：以前的动作状态在
"被盖住"分支之后才推进，结果一有窗口压住它，压扁/跳跃就停在最后一帧，
看起来像"一直瘪着/卡死"。

打包是「目录版」不是单文件版：单文件版启动要解包到临时目录，在某些被管控
的电脑上会报 "Could not create temporary directory!"，目录版没有这个问题。
